# Week 1 — Course Intro & Major Python AI Libraries

**Lecture theme:** Course introduction; hands-on practice with NumPy, pandas, and matplotlib — the three libraries every AI project in this course will build on.

## Project: Student Exam Score Explorer

You'll work with a small, made-up class roster (study hours + scores in three subjects) and use it to practice the core moves you'll reuse all semester:

- **NumPy** — fast numeric arrays, `mean`/`std`/`max`/`min`, correlation
- **pandas** — loading tabular data into a `DataFrame`, filtering, sorting, `groupby`
- **matplotlib** — histograms, scatter plots, bar charts

By the end you'll be able to load any small dataset and answer "what does this data look like?" — the first step of every AI project.
