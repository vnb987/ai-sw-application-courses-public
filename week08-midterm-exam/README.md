# Week 8 — Midterm Exam

**Covers:** Weeks 1–7 (Python AI libraries; supervised learning I & II; unsupervised learning I & II; data representation; model evaluation).

No new project this week. Instead there's an optional, ungraded **self-check
review notebook** that strings together one small step from each of weeks 1–7
into a single end-to-end pipeline — a good way to confirm the pieces connect
before the exam.

## Suggested exam prep

- Re-run each week's "Try it yourself" exercises without looking at the solution first
- Be able to explain, in one sentence each: k-NN, linear regression, decision
  trees, random forests, PCA, k-means, one-hot encoding, cross-validation,
  precision vs. recall
- Know which evaluation metric you'd reach for in a classification problem
  where false negatives are costly (see Week 7)
